# ADR-001：技术栈选型

- 编号：ADR-001
- 日期：2026-09-21
- 状态：已接受
- 背景：测试平台需支持查日志、查数据库、查 Redis、接口测试、性能测试、工具集等 16 模块；单人 + AI 开发；后续需对接 ELK/Loki、JMeter 引擎等。

## 决策

| 层 | 选型 | 版本 |
|:---|:-----|:-----|
| 前端框架 | Vue 3 + Vite | Vue 3.4+ / Vite 5+ |
| 前端 UI | Element Plus | 2.x |
| 前端状态/路由 | Pinia + Vue Router | 4.x |
| 后端 | Java Spring Boot | 17 / Boot 3.2+ |
| ORM | MyBatis-Plus | 3.5.x |
| 数据库 | MySQL | 8.0 |
| 认证 | JWT（jjwt） | 0.12.x |
| 后端接口风格 | REST + 统一响应体（code/msg/data） | — |

## 理由
1. **Vue3 + Element Plus**：后台管理类系统国内生态最成熟，组件齐全（表格/表单/树/标签），与需求文档 16 模块的后台形态高度匹配；Vite 开发体验好。
2. **Spring Boot 3 + MyBatis-Plus**：Java 生态招聘友好、文档多；MyBatis-Plus 单表 CRUD 零 SQL，适合快速迭代；后续对接 ELK/Loki/JMeter 均有成熟客户端。
3. **MySQL 8**：平台自身元数据（用户/用例/环境/报告）关系型天然合适，团队已熟悉。
4. **JWT + RBAC**：无状态认证适合前后端分离 + 后续 CI 触发场景；菜单级 RBAC 满足多角色（测试/开发/运维/管理员）。

## 后果
- 优点：开发效率高、人才好找、生态齐全。
- 成本：Java 内存占用高于 Go（可接受）；需维护 JWT 密钥轮换。
- 待确认（PRD 第 7 章）：多租户/多项目空间若启用，RBAC 需扩展项目维度（ADR-002 预留）。

## 备选方案
- Go（Gin）：部署轻量，但生态与招聘弱于 Java，未选。
- Spring Data JPA：复杂查询不如 MyBatis-Plus 直观，未选。
