# 环境搭建说明

> 针对 Windows 开发机（本项目开发环境）。更新时间：2026-09-21

## 前置依赖

| 依赖 | 版本要求 | 安装/检查命令 |
|:-----|:---------|:-------------|
| Node.js | ≥ 18 | `node -v` |
| JDK | 17 | `java -version` |
| Maven | ≥ 3.8 | `mvn -v` |
| MySQL | 8.0 | `mysql --version` |
| Git | 任意 | `git --version` |

## 环境变量

| 变量 | 说明 | 示例 |
|:-----|:-----|:-----|
| `DB_URL` | MySQL 连接串 | `jdbc:mysql://localhost:3306/test_platform?useSSL=false&serverTimezone=Asia/Shanghai` |
| `DB_USER` | 数据库账号 | `root` |
| `DB_PASS` | 数据库密码 | （本地） |
| `JWT_SECRET` | JWT 签名密钥（≥32字符） | 开发用默认值，生产必须环境变量注入 |

> 后端 `application.yml` 读取以上环境变量；开发默认值仅限本地。

## 安装步骤

### 1. 初始化数据库
```bash
mysql -uroot -p < backend/sql/init.sql
```
创建库 `test_platform`，初始化用户/角色/菜单/环境/用例表与种子数据（admin/admin123）。

### 2. 启动后端
```bash
cd backend
mvn spring-boot:run          # 默认 http://localhost:8080
```
健康检查：`curl http://localhost:8080/api/health`

### 3. 启动前端
```bash
cd frontend
npm install
npm run dev                  # 默认 http://localhost:5173，/api 代理到 8080
```

### 4. 访问
浏览器打开 `http://localhost:5173`，登录 `admin / admin123`。

## 常见问题

| 问题 | 解决 |
|:-----|:-----|
| 端口被占用 8080/5173 | 改 `application.yml` 的 `server.port` / `vite.config.js` 的 `server.port` |
| 前端调接口 404 | 确认后端已启动、`vite.config.js` 代理指向正确端口 |
| MySQL 连不上 | 检查服务是否启动、`DB_URL/DB_USER/DB_PASS` 是否正确 |
| 中文乱码 | 确认 MySQL 连接串带 `characterEncoding=utf8`，库表用 utf8mb4 |
